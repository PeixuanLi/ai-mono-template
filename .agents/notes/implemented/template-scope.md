# 模板形态:全量即用

## 决策

模板携带的机制全部开箱即跑;对"仓库长大后才有的结构"用"存在才查"放行,而不是提供按需激活开关。

## 理由

机制的价值在执法连续性;按需激活意味着每个团队要重新决策一次"要不要",默认路径应是最优路径。结构感知让空仓库不误报。

## 考虑过的替代方案

- 薄模板+进阶手册:把执法脚本变成可选件,违背门禁优先论(见 [门禁优先于约定](gate-over-convention.md))。
- 机制即插件(可拆卸模块):机制间依赖(笔记↔格式门禁↔预算与归档登记)会变成隐式耦合,扁平结构更可读。
