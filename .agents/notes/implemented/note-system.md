# 决策笔记制度本身

## 决策

有真取舍的决策写进 .agents/notes/ 的四个生命周期目录;必含"考虑过的替代方案";格式由 verify-agent-note-format 门禁执法,归档由 manifest 冻结。小决策(命名、局部重构)不写笔记。

## 理由

AI 主笔的开发节奏下,取舍理由若只存在会话记忆里,决策就会被反复重审;笔记把"为什么、放弃了什么"变成仓库资产。仅靠约定无法维持格式(见 [门禁优先于约定](gate-over-convention.md)),所以制度必须自带门禁。

## 考虑过的替代方案

- ADR 目录:状态生命周期需要自制;本制度以目录编码状态,天然可机检。
- wiki/issue 评论:不可门禁、不可 diff、链接易腐。
- 只留代码注释:注释装不下"放弃了什么",也装不下跨 PR 的取舍背景。
