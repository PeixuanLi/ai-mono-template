# 写作规范

适用于 docs/、.agents/notes/、AGENTS.md 与技能的全部文本。

## 只留结论与事实

判据:HEAD 上的读者,不访问任何会话记录、PR 讨论、未提交草稿,能否解析每个引用、核实每句话。
不能 → 删掉或补全。

## slop 清单(LLM 文档病态,逐条禁止)

- 推理转录:"我们首先考虑…然后决定…"——过程留给会话,不进仓库。
- 重复规则:同一事实出现两处;一个事实一个 home,其余互链。
- 实现状态标注:"本文档尚待完善"、"TODO:补充"——要么写完,要么不提交。
- 强调通胀:不必要的粗体、感叹、重要性渲染。
- 无主语模糊指代:"如前所述"、"显然"。

## 形态约定

- 文件以恰好一个换行结尾;中文与英文/数字之间加空格。
- 字数预算见 budgets.json(docs 150 行/笔记 120 行),只紧不松。
- docs 与笔记的分工见 .agents/notes/README.md:docs 答 what/how,笔记答 why/why-not。
